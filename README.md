# Lost & Found ITG

Aplikasi Mobile Lost & Found untuk komunitas mahasiswa Institut Teknologi Garut (ITG). Aplikasi ini memudahkan mahasiswa untuk melaporkan barang yang hilang atau ditemukan di lingkungan kampus.

## Deskripsi Aplikasi
Lost & Found ITG adalah platform berbasis mobile yang dirancang khusus untuk membantu mahasiswa ITG dalam mengelola informasi mengenai barang-barang yang hilang atau ditemukan. Dengan antarmuka yang modern dan mudah digunakan, aplikasi ini bertujuan untuk meningkatkan peluang kembalinya barang ke pemilik aslinya.

## Tujuan Aplikasi
* Menyediakan pusat informasi terpadu untuk barang hilang dan ditemukan di ITG.
* Mempercepat proses pengembalian barang kepada pemiliknya.
* Meningkatkan rasa aman dan kepedulian antar sesama mahasiswa.

## Fitur Utama
* **Login & Register**: Keamanan akses menggunakan akun mahasiswa.
* **Home Page**: Dashboard aktivitas terbaru dengan fitur pencarian barang berdasarkan nama atau lokasi.
* **Report Item**: Form pelaporan barang hilang atau ditemukan lengkap dengan kategori dan info kontak.
* **Item Details**: Informasi detail barang beserta status (Lost, Found, Claimed).
* **Profile (CRUD)**: Pengelolaan profil pengguna termasuk fitur edit Nama, Email, dan Nomor WhatsApp.

## Teknologi yang Digunakan
* **Bahasa**: Dart
* **Framework**: Flutter (Material 3)

## Cara Menjalankan Aplikasi
1.  Pastikan Anda telah menginstal **Flutter SDK** dan **Dart**.
2.  Clone atau download repository ini.
3.  Buka direktori proyek di terminal.
4.  Jalankan perintah berikut untuk mengunduh dependencies:
    ```bash
    flutter pub get
    ```
5.  Jalankan aplikasi di emulator atau perangkat fisik:
    ```bash
    flutter run
    ```
